## 一、项目概况

- **题目**：声安浙里，深谙民生——城市化背景下浙江环境噪声污染现状与杭甬温民生感知调查
- **论文文件**：`background/论文.tex`（xelatex + cumcmthesis，约 1545 行）
- **数据**：浙江省杭甬温环境噪声污染调查问卷（数字版 + 文本版，493 份回收、467 份有效）
- **分析流程**：数据预处理 → 信效度检验 → EFA 降维 → 聚类细分 → 有序 Logistic → 多模型对比（XGBoost/RF，贝叶斯调参）→ SEM 传导机制 → 决策概率/边际效应
- **环境**：conda 环境 `jingsai-env`（Python 3.x + pandas/scipy/statsmodels/sklearn/xgboost/pingouin/factor_analyzer）

### 5.1 对比结果（独立测试集，三模型，均用分类器）

| 模型 | Accuracy | Macro-F1 | Kappa |
|---|---|---|---|
| 有序 Logistic | 0.447 | 0.374 | 0.218 |
| 随机森林 | 0.436 | 0.360 | 0.200 |
| XGBoost（调参后） | 0.426 | 0.331 | 0.192 |

- 三模型均为「分类」任务（有序 Logistic 为有序分类，XGBoost/RF 为多分类 softprob），在独立测试集（20% 留出）上评估，避免调参/评估同源偏差。
- 有序 Logistic 综合最优；随机森林反超 XGBoost（分类器下 Macro-F1 0.360 vs 0.331），说明「回归+四舍五入切分」此前拖累了树模型。
- 指标雷达图采用 5 指标（Accuracy/Precision/Recall/Specificity/Kappa，均宏平均，五边形）。

### 5.2 贝叶斯调参（q6_tune）

- 方法：optuna TPE 采样器，30 次试验，目标 = Macro-F1 最大化，只在训练集上做（留出独立测试集）。
- 最优 Macro-F1：0.3003（训练集 5 折 CV）。
- 最优超参数：learning_rate=0.274、max_depth=5、n_estimators=254、subsample=0.601、colsample_bytree=0.825、reg_lambda=0.244、reg_alpha=2.290、min_child_weight=1。
- 注意：调参对象为 XGBClassifier（multi:softprob），非回归。

### 5.3 聚类结果（q3_cluster）

- 方法：KMeans++ 对 F1~F4 因子得分聚类，轮廓系数最大定 K=5，四因子 ANOVA 全部极显著（聚类有效）。
- 5 类人群（按因子均值特征）：

| 类型 | 因子特征 | 命名建议 |
|---|---|---|
| 全低 | F1~F4 均低 | 低敏感低困扰型 |
| 中间 | 各因子接近均值（最大群体） | 一般型 |
| F4 高 | 生活场景噪声源高 | 生活场景噪声困扰型 |
| F3 高 | 典型环境噪声源高 | 典型环境噪声暴露型 |
| F1F2 高 | 身心+情绪高 | 身心情绪高敏感型 |

### 5.4 结构方程模型 SEM（q7_sem）

- 方法：`semopy`，测量模型（4 个潜变量 F1~F4 各对应 EFA 题项）+ 结构模型（`F3/F4 → F1/F2 → 满意度`）+ 协方差 `F1 ~~ F2`。
- 拟合指标：χ²=261.205（df=81）、CFI=0.916、TLI=0.891、RMSEA=0.069，整体可接受。
- 结构路径系数（标准化）：

| 路径 | 系数 | 显著性 |
|---|---|---|
| F3 环境源 → F1 身心 | 0.370 | \*\*\* |
| F4 生活源 → F1 身心 | 0.072 | ns |
| F3 环境源 → F2 情绪 | 0.216 | \* |
| F4 生活源 → F2 情绪 | 0.352 | \*\* |
| F1 身心 → 满意度 | 0.003 | ns |
| F2 情绪 → 满意度 | −0.269 | \*\*\* |
| F3 环境源 → 满意度 | −0.214 | \* |
| F4 生活源 → 满意度 | −0.277 | \* |
| F1 ~~ F2 | 0.188 | \*\*\* |

- 结论：**情绪（F2）是满意度最主要的直接传导通道**（−0.269\*\*\*），与修复后有序 Logistic 中 F2 系数最强（−0.583）一致；身心（F1）对满意度的直接效应不显著（被 F2 吸收/中介），即「噪声先损害身心，再通过情绪最终影响满意度」。噪声源（F3/F4）既直接、又间接影响满意度。

### 5.5 平行性检验与敏感性分析（q4_logistic 的 sensitivity.csv）

- 平行性检验拒绝比例优势假设：χ²=87.14（df=54，p=0.003）。换链接函数（probit）同样拒绝（p=0.005），说明偏离是数据特性、非链接函数选择问题。
- 敏感性分析：拟合广义有序模型（每个切分点独立系数，等价 gologit），F1~F4 在 4 个切分点的系数**全部为负、方向一致**（F1 −0.337/−0.124/−0.119/−0.917，F2 −0.152/−0.417/−0.625/−1.088，F3/F4 同理），说明「噪声影响负向满意度」的核心结论稳健，偏离仅是效应强度随切分点变化、而非方向反转。
- 处理决策：**不换 gologit 主模型**（72 参数、可解释性下降），保持比例优势 + 敏感性分析，二者配合将「平行性被拒」转化为「核心结论稳健」。

### 5.6 决策概率与边际效应（q8_decision）

- 方法：基于有序 Logistic，将分析重心从「5 级分类准确率」转向治理决策量——P(Y≤2) 不满意概率、P(Y≥4) 满意概率、E[Y] 期望满意度、群体概率差距、可干预变量的平均边际效应（AME）。
- 基线：P(Y≤2)=44.84%、P(Y≥4)=25.34%、E[Y]=2.78。
- 边际效应（对不满意概率 P(Y≤2) 的平均边际效应）：

| 干预变量 | ΔP(Y≤2) |
|---|---|
| 隔音墙（无→有） | −13.76 pp（最强） |
| 县城（vs 乡镇农村） | +8.20 pp |
| 郊区（vs 乡镇农村） | +4.46 pp |
| 杭州（vs 温州） | +3.33 pp |
| 主城区（vs 乡镇农村） | −3.92 pp |
| 宁波（vs 温州） | −1.68 pp |

- 群体差距：18 岁以下不满意概率最高（58.68%）、杭州三市最高（49.61%）、无隔音墙 50.24%（vs 有隔音墙 31.15%）。
- 治理启示：① 隔音改造是第一优先级工程手段；② 青少年是重点人群；③ 杭州是重点城市。注意「主城区 vs 乡镇农村」方向与常识相反（−3.92 pp），系数据缺陷同源，建议谨慎表述。

## 八、论文章节结构建议

主线为「降维 → 细分 → 找影响因素 → 拆机制 → 给建议」，各分析的定位如下：

| 分析 | 定位 | 建议放置 |
|---|---|---|
| EFA 降维 | 铺垫 | 第 6 章 |
| 人群聚类 | 细分 | 第 7 章 |
| 有序 Logistic | 核心（满意度直接影响因素） | 第 8 章 |
| XGBoost/RF 对比 | 佐证（降级为「模型稳健性检验」小节） | 第 8 章内一小节 |
| SEM | 深化（传导机制） | 第 9 章 |
| 决策概率 | 落地（治理建议的量化支撑） | 第 10 章 |

推荐骨架：

```
第 6 章  EFA 降维
第 7 章  人群聚类
第 8 章  有序 Logistic：满意度影响因素（核心）
         ├─ 8.1 直接影响（系数/OR）
         ├─ 8.2 模型稳健性检验（XGBoost/RF 对比，一小节）
         └─ 8.3 平行性假设与敏感性分析
第 9 章  SEM：噪声影响传导机制
第 10 章 决策概率与治理建议
第 11 章 结论
```

要点：**机器学习对比不要和有序 Logistic 并列成独立章**，而应降为第 8 章内的「稳健性检验」小节，一句话带过「对比 XGBoost、随机森林，有序 Logistic 仍最优，说明选型合理」。
