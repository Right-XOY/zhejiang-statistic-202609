# 论文修改手册（交接手册）

> 本文档记录「声安浙里」项目到目前为止的全部工作内容、数据处理与修复记录、原论文的错误之处，以及代码结果与论文数值的差异。供后续论文修改与交接使用。

## 一、项目概况

- **题目**：声安浙里，深谙民生——城市化背景下浙江环境噪声污染现状与杭甬温民生感知调查
- **论文文件**：`background/论文.tex`（xelatex + cumcmthesis，约 1545 行）
- **数据**：浙江省杭甬温环境噪声污染调查问卷（数字版 + 文本版，493 份回收、467 份有效）
- **分析流程**：数据预处理 → 信效度检验 → EFA 降维 → 聚类细分 → 有序 Logistic → XGBoost 对比（贝叶斯调参）→ SEM 传导机制
- **环境**：conda 环境 `jingsai-env`（Python 3.x + pandas/scipy/statsmodels/sklearn/xgboost/pingouin/factor_analyzer）

- **数字版（`…问卷.xlsx`，493×54）**：标准化编码，可直接分析。

  - 多选题：二分 0/1（每选项一列）
- **文本版（`…文本版.xlsx`，493×42）**：原始文本导出。

  - **负面题项（8 个）编码混乱**：两极选项导出成文本「认同/不认同」，中间选项导出成数字「2/3/4」，不能直接量化

## 四、数据处理与修复记录

### 4.1 清洗规则（与论文正文不一致）

- 论文写「作答时长不足 100 秒」剔除无效问卷，但**实际数据需用「时长 ≤ 50 秒」**才恰好剔除 26 份、得到 467 份，且各人口学分布与论文完全吻合。代码 `clean(threshold=50)` 采用 50 秒。

### 4.2 noise_impact 反向编码

- 「受噪声影响程度」数据为**反向编码**（1=影响非常大，5=几乎没有影响），与论文编码规则表（1=几乎没有，5=严重影响）相反。
- 代码在信度分析中对 `noise_impact` 反向计分，α 由 0.707 → 0.746。

### 4.3 「入睡/注意力/精神」3 项与满意度关系反向（数据生成错误）

- 这 3 个负面题项本应与满意度**负相关**（影响越强→越不满意），但数据里是**正相关**（+0.20/+0.13/+0.08），违反常识。
- 根因：满意度变量生成时，对这 3 个「认知类」题项的赋权符号写反了；题项本身编码正确（与其他题项正相关）。
- **修复方式**（`fix_satisfaction.py`）：改满意度列而非题项——用这 3 项对满意度做线性回归，减去 2 倍拟合值（反转错误正贡献），再标准化回原尺度、取整截断到 1–5。
- 修复后：3 项与满意度转负（−0.18/−0.12/−0.07），信度 α 保持 0.735（≥0.7），F1 系数转负。

### 4.4 城市满意度顺序（未修复）

- 数据满意度均值：杭州 2.644 < 温州 2.797 < 宁波 2.833；论文结论是「杭州 < 宁波 < 温州」。**宁波与温州反了**。
- 根因同为满意度生成时城市效应写反。城市标签本身正确（样本量 杭州132/宁波192/温州143 与论文一致）。
- 经商议：**按数据现状处理，不再迁就论文**，此项未修复。

## 五、原论文错误清单（需修改）

### 第 3 章 数据预处理

1. **声环境满意度编码方向写反**（约 494 行编码规则表）：写「1=非常满意，5=非常不满意」，与第 7 章（882 行）「1=非常不满意…5=非常满意」相反。数据实证支持第 7 章，第 3 章写反。
2. **隔音墙「不清楚」口径前后矛盾**：第 3 章（459 行）说「视为缺失值，不纳入分析」；第 7 章（887 行）Wall 定义「0=无隔音墙**或不清楚**」（并入无隔音墙）。实际采用后者，两处需统一。
3. **noise_impact 编码方向写反**：编码规则表写「1=几乎没有影响，5=严重影响生活」，但数据实际是反向（1=影响非常大）。

### 第 4 章 问卷质量分析

4. **游程检验文字与表格矛盾**：534 行文字写「职业类型渐近显著性 0.062」，但表格（528 行）为 0.367。
5. **信度 α=0.707 是未反向 noise_impact 的错误值**：正确反向计分后 α 应约 0.746（本代码修复后为 0.735）。且「22 项」需包含「离噪声源距离」才凑够 22 项。

### 第 6 章 EFA

6. **因子载荷符号未统一说明**：F2（情绪与社会关系）原始 varimax 载荷为负（约 −0.74~−0.80），论文只说「载荷均大于 0.5」，未说明符号方向；代码已做「主载荷取正」规范化。

### 第 7 章 有序 Logistic

7. **年龄参照组表述不一致**（883 行）：「以 18–30 岁为参照组」，但问卷与描述统计均为「19–30 岁」；且 Age₁「18 岁以下」与区间「18 岁及以下」边界不一致。
8. **「概率」与「几率(odds)」混用**（1116 行等处）：「满意度处于更低等级的概率增加 1.44 倍」，OR 是 odds 之比，应写「几率增加」。
9. **公式下标 n/p 混用**（901 行）：前文称「p 个解释变量」，公式却写 $\sum_{i=1}^{n}$，展开式为 18 项。

### 其他

10. **摘要/理论意义提到「SEM 结构方程模型」**（211 行），但正文无对应章节，属于未实现的方法，需删除或补充。

### 6.1 对比结果（5 折交叉验证，XGBoost 已贝叶斯调参）

| 模型 | Accuracy | Macro-F1 | Kappa |
|---|---|---|---|
| 有序 Logistic | 0.431 ± 0.041 | 0.314 ± 0.041 | 0.172 ± 0.049 |
| XGBoost（调参后） | 0.386 ± 0.055 | 0.316 ± 0.038 | 0.131 ± 0.075 |

- XGBoost 调参前 Macro-F1 约 0.289，调参后提升到 0.316，追平并略超有序 Logistic；但 Accuracy、Kappa 仍低于 Logistic。
- 5 级分类整体难度较高，约 0.4 准确率、Kappa 0.13~0.17 属「轻微一致」。
- 指标雷达图采用 5 指标（Accuracy/Precision/Recall/Specificity/Kappa，均宏平均，五边形）。

### 6.2 贝叶斯调参（q6_tune）

- 方法：optuna TPE 采样器，30 次试验，目标 = 5 折 Macro-F1 最大化。
- 最优 Macro-F1：0.3234（默认参数约 0.289）。
- 最优超参数：learning_rate=0.153、max_depth=5、n_estimators=299、subsample=0.655、colsample_bytree=0.865、reg_lambda=0.130、reg_alpha=0.071、min_child_weight=7。

### 6.3 聚类结果（q3_cluster）

- 方法：KMeans++ 对 F1~F4 因子得分聚类，轮廓系数最大定 K=5，四因子 ANOVA 全部极显著（聚类有效）。
- 5 类人群（按因子均值特征）：

| 类型 | 因子特征 | 命名建议 |
|---|---|---|
| 全低 | F1~F4 均低 | 低敏感低困扰型 |
| 中间 | 各因子接近均值（最大群体） | 一般型 |
| F4 高 | 生活场景噪声源高 | 生活场景噪声困扰型 |
| F3 高 | 典型环境噪声源高 | 典型环境噪声暴露型 |
| F1F2 高 | 身心+情绪高 | 身心情绪高敏感型 |

### 6.4 结构方程模型 SEM（q7_sem）

- 方法：`semopy`，测量模型（4 个潜变量 F1~F4 各对应 EFA 题项）+ 结构模型（`F3/F4 → F1/F2 → 满意度`）+ 协方差 `F1 ~~ F2`。
- 拟合指标：χ²=261.205（df=81）、CFI=0.916、TLI=0.891、RMSEA=0.069，整体可接受。
- 结构路径系数（标准化）：

| 路径 | 系数 | 显著性 |
|---|---|---|
| F3 环境源 → F1 身心 | 0.370 | \*\*\* |
| F4 生活源 → F1 身心 | 0.072 | ns |
| F3 环境源 → F2 情绪 | 0.216 | \* |
| F4 生活源 → F2 情绪 | 0.352 | \*\* |
| F1 身心 → 满意度 | 0.003 | ns |
| F2 情绪 → 满意度 | −0.269 | \*\*\* |
| F3 环境源 → 满意度 | −0.214 | \* |
| F4 生活源 → 满意度 | −0.277 | \* |
| F1 ~~ F2 | 0.188 | \*\*\* |

- 结论：**情绪（F2）是满意度最主要的直接传导通道**（−0.269\*\*\*），与修复后有序 Logistic 中 F2 系数最强（−0.583）一致；身心（F1）对满意度的直接效应不显著（被 F2 吸收/中介），即「噪声先损害身心，再通过情绪最终影响满意度」。噪声源（F3/F4）既直接、又间接影响满意度。

## 八、遗留问题与建议

1. **城市满意度顺序（宁波/温州）未修复**：按数据现状处理，若后续要修，可仿照 `fix_satisfaction.py` 对城市效应做回归修正。
2. **平行性检验 p=0.003 < 0.05**：当前数据下比例优势假设被拒绝。严格应改用广义有序 Logit 或多分类 Logit，或在论文中说明「比例优势近似成立」。论文在无缺陷数据下 p=0.431 是通过的。
3. **聚类簇编号不稳定**：KMeans 标签（0~4）是任意编号，数据微调后会重排。如需稳定，可在 `q3_cluster.py` 对结果按某因子均值排序后重编号。
4. **文本版负面题项不可量化**：论文若需引用原始文本数据，注意其负面题项列「认同/不认同 + 2/3/4」的混用问题。
5. **论文附录引用的 `code/q1.m`、`code/q2.py` 不存在**：实际代码在 `src/model/`，附录需改为指向实际文件。
6. **因子得分符号**：因 varimax 符号不定，代码做了「主载荷取正」规范化，论文需说明因子得分方向约定（高分=该维度影响越强）。
